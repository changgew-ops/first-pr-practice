# 아이돌 매니저: 서바이벌 (Mnet 걸그룹 시즌 1) — 설계 문서

개인 프로젝트. 실존 레이블/방송사(Mnet)는 실명 사용, **참가자 101명과 제작진은 전원 가상 인물**.

## 1. 핵심 컨셉
- 플레이어 = 매니저. 12명의 주인공 후보 중 1명을 골라 12주 시즌을 함께 한다.
- 101명 중 **TOP 11 데뷔**. 톤은 밝은 청춘 + 악마의 편집(억까).
- 목표는 "왜 잘했는지 / 왜 순위가 바뀌었는지 / 내 선택이 어디에 영향을 줬는지"를 플레이어가 납득하는 것.

## 2. 시즌 구조 (12주)
| 주차 | 구분 | 비고 |
|---|---|---|
| 1 | 첫 평가 | 등급 평가, 초기 순위 |
| 2~11 | 5개 라운드, 라운드당 **준비 주간 + 방송 주간** | 방송 주간 끝에 순위 발표/탈락 |
| 12 | 최종 생방송 | 1인 투표, TOP 11 확정 |

탈락 곡선: 101 → 60 → 35 → 22 → 16 → 13 → **11**

| | 준비 주간 | 방송 주간 |
|---|---|---|
| 활동 | 파트 협상, 훈련, 분석, 인터뷰 | 컨디션, 홍보, 무대, 논란 대응 |
| 관계 | 파트 경쟁, 갈등 | 갈등의 결과, 무대 후 대화 |
| 순위 | 예상 순위·지지 추세 (비공식) | 투표 마감 시 공식 순위 |

준비 주간에는 연습 영상·인터뷰·중간 평가가 공개되어 무대가 없어도 반응이 생긴다.

## 3. 투표 모델 (팬이 생기고, 그 팬이 투표한다)
무대·방송 노출 → 관심 유입 → 호감에 따라 팬 전환 → 팬 유지·이탈 → 투표

| 값 | 의미 |
|---|---|
| 인지도 | 얼마나 많은 시청자가 아는가 |
| 호감도 | 아는 사람이 얼마나 좋게 보는가 |
| 고정 팬 수 | 꾸준히 지지하는 팬 규모 |
| 팬덤 결속 | 팬이 얼마나 적극적으로 투표하는가 |

`투표수 = 고정 팬 투표 + 일반 시청자 선택 + 미션 베네핏` (무작위는 ±5% 이내).
논란은 인지도만 올리고 호감도를 깎으므로 순위 상승으로 직결되지 않는다.

### 투표 방식 (시즌 시작부터 공개, 발표 구간마다 집계 초기화 / 팬덤은 유지)
| 구간 | 선택 인원 | 유리한 쪽 |
|---|---|---|
| 첫 평가, R1~R2 | 11명 | 두루 호감인 참가자 |
| R3~R4 | 5명 | 중간 |
| R5 | 3명 | 고정 팬덤 |
| 최종 | 1명 | '최애'로 선택받는 힘 |

## 4. 매니저 행동
- **기본 일정**(훈련·식사·수면)은 자동 진행.
- **집중 행동 2개/주**: 특별 훈련, 분석, 협상, 중재, 홍보, 컨디션 등.
- **긴급 사건 대응**은 사건 안에서 선택하되, 추가 실행은 자금/슬롯이 든다.
- **분석**은 구체적인 수치 기반 피드백을 준다.

## 5. 억까 = 사건의 연쇄
`파트 갈등 → 제작진 주목 → 인터뷰 요청 → 편집 방향 결정 → 방송 → 대응/후속 반응`
- 징후 힌트: 분석을 했거나 신뢰도가 높으면 "이 질문은 일부만 쓰일 위험이 있다" 같은 경고가 보인다.
- 대응 3갈래: **예방 / 수습 / 회복**. 성공도 두 종류(피해 감소 / 역전 서사로 팬 증가).
- 큰 억까 직후에는 밝은 일상 이벤트로 회복 여유를 준다.

## 6. 위기 단계 (즉시 하차 없음)
위험 경고 → 수행 능력 저하 → 휴식·상담 or 강행 → 지속 시 하차 논의.
멘탈 위기에서는 매니저 신뢰도에 따라 속마음을 털어놓거나 숨긴다.

## 7. 엔딩 = 3축 조합
오디션 성적 × 개인 서사 × 매니저와의 관계. 조기 탈락도 서사에 따라 좋은 결말이 될 수 있다.
