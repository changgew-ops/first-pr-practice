# 실제 기록으로 능력치 만들기

`data/stats/base.csv` 를 두고 `npm run generate` 를 실행하면, 로스터 CSV(`data/rosters/<구단id>.csv`)에 있는
선수 중 이름이 같은 선수의 능력치를 이 기록으로 계산한다. 파일이 없으면 가상 능력치를 쓴다.

## 파일 형식
`_template.csv` 참고. 한 줄 = 선수 한 명의 시즌 합계 기록.

| 컬럼 | 뜻 |
|---|---|
| name | 선수 이름 (로스터 CSV와 똑같이) |
| games | 출전 경기 수 |
| minutes | 총 출전 시간(분) |
| pts, reb, ast, stl, blk | 득점, 리바운드, 어시스트, 스틸, 블록 합계 |
| fgm, fga | 야투 성공·시도 (2점+3점) |
| tpm, tpa | 3점 성공·시도 |
| ftm, fta | 자유투 성공·시도 |

- 경기당 평균만 있으면 `평균 × 경기 수`로 합계를 만든다. 출전 시간은 `경기당 출전 시간 × 경기 수`.
- `#`으로 시작하는 줄은 무시된다.

## 능력치가 만들어지는 방식
1. 출전 시간이 300분 이상인 선수들로 리그 분포를 만든다.
2. 지표별로 리그 안의 순위(백분위)를 정규분포 점수로 바꾼다. 절대 수치가 아니라 **그 시즌 리그 안의 순위**다.
3. 능력치별로 지표를 섞는다.
   - 슛: 진짜 슈팅 효율(TS%), 3점 성공률, 자유투 성공률, 36분당 득점
   - 패스: 36분당 어시스트
   - 수비: 36분당 스틸·블록
   - 리바운드: 36분당 리바운드
   - 운동능력·체력: 기록으로 직접 재기 어려워 **대용 지표**(득점·리바운드·스틸·블록, 경기당 출전 시간)를 쓴다.
4. 리그 평균 62, 편차 10으로 되돌린다 (`league-rules.json`의 `ratingModel`).
5. 출전 시간이 1,200분보다 적으면 기록을 덜 믿고, 포지션 평균 쪽으로 당긴다.

시뮬레이션에서 나온 기록으로 같은 변환을 돌려 원래 능력치와 비교하면 슛 0.92~0.98, 리바운드 0.95,
패스 0.90, 수비 0.73~0.80의 상관이 나온다. 운동능력과 체력은 0.6~0.75 수준이다.

## 주의
- 실제 기록은 KBL 공식 기록실 등 공개 자료에서 직접 확인해 옮긴다. 에이전트가 추측해서 채우지 않는다.
- 이 폴더의 `_template.csv`는 형식 예시이며 실제 선수 기록이 아니다.
