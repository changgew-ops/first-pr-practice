# 실제 선수 풀

KBL 기록실·선수 화면에서 옮긴 자료로 실제 선수 풀을 만든다. 설계는 `docs/GAME_DESIGN.md` 5.8.1.

| 파일 | 사람이 고치나 | 설명 |
|---|---|---|
| `registry.csv` | 화면에서 옮김 | KBL 선수 > 등록선수 화면(2026-10-22): 현재 소속·등번호·포지션(G/F/C)·구분(d 국내, f 외국, a 아시아쿼터)·드래프트 연도 |
| `team-2025-26.csv` | 화면에서 옮김 | 2025-26 소속(선수기록 화면의 팀 아이콘 판독). 동명이인 구분과 이적 확인용 |
| `team-2024-25.csv`, `team-2023-24.csv` | 화면에서 옮김 | 2024-25(203명), 2023-24(200명) 소속. 같은 방식이고 시즌 중 이적한 선수는 마지막 소속 |
| `team-overrides.csv` | 필요할 때 | 아이콘 판독을 사람이 확인해 바로잡은 값(시즌·이름·구단·이유) |
| `icon-templates.json` | 아니오 | 팀 아이콘 10종의 기준 이미지(판독 도구가 쓴다) |
| `name-aliases.csv` | 필요할 때 | 기록 시트와 등록선수 화면의 표기가 다른 이름 |
| `team-map.csv` | **정정할 때만** | 채운 칸만 효과가 있다(팀·나이·포지션·번호·국적). 나머지 열은 참고용 |
| `real-pool.json` | 아니오 | `npm run build:real`이 만드는 선수 풀 (능력치·코스트·소속) |

## 흐름
`npm run build:real` → (필요하면 `team-map.csv` 정정) → `npm run apply:real` → `npm run generate` → `npm test`

- **소속**은 `team-map.csv` 정정 > `registry.csv`(현재 소속) 순으로 정한다. 등록선수 목록에 없는 선수(은퇴·군 복무·방출 등)는 게임에 넣지 않는다.
- **능력치**는 2025-26과 2026-27 기록으로 계산한다(`data/stats/`). 올해 기록이 없는 등록 선수는 기록 없는 선수로 두고 생성기가 이름을 시드로 능력치를 채운다.
- **포지션**: 등록 포지션이 가드·포워드·센터 세 가지뿐이라, 가드는 PG/SG, 포워드는 SF/PF로 기록(36분당 어시스트·리바운드)을 보고 나눈다. 정정하려면 `team-map.csv`의 `position`.
- **나이**는 드래프트 참가 기록의 생년월일이 있으면 그것으로(2024·2025 드래프트 지명자 약 40명), 없으면 드래프트 연도 + 22세로 어림한다. 드래프트 기록이 없는 외국 선수·아시아쿼터는 생성기가 채운다.
- **아시아쿼터**는 아직 별도 칸이 없어 국내 선수로 취급한다(`real-pool.json`의 `asiaQuota`로 표시).
- **로스터**는 국내 12·외국 2로 출전 시간 순으로 뽑고, 다섯 포지션이 모두 있도록 보충하거나 포지션을 바꾼다. 바뀐 내용은 `apply:real` 출력에 나온다.
- 동명이인은 `이정현(1)`, `이정현(2)`처럼 구분되고, 로스터에는 동명이인이 없으면 꼬리표를 뗀 이름이 들어간다.
- 같은 이름이 두 번 이상 겹쳐 짝을 못 정한 경우(예: 최승욱)는 기록 없는 선수로 두고 `build:real`이 알려 준다.

## 판독 방법과 검증
- `team-2025-26.csv`: 아이콘 10종을 구분하고, 같은 아이콘을 단 선수들의 최대 승·패가 구단 시즌 합계(정규리그+플레이오프)와 맞는 구단으로 짝지었다. 짝은 하나로 정해졌고 193명 모두 승패 제약을 어기지 않았다.
- `registry.csv`: 10개 구단 모두 외국 2명이고 구단 안에서 등번호가 겹치지 않는다(테스트로 확인). 등록선수 화면과 2025-26 소속이 다른 선수는 이적한 선수다.
- 2025-26 소속은 순위 1~193위를 모두 읽었다(41~60위는 스크린샷, 나머지는 녹화). 나무위키 2025-26 시즌 문서의 트레이드·FA 이동과도 맞는지 확인했다(장재석→KCC, 이승현·전준범→현대모비스, 김선형→KT, 한호빈·이근휘→삼성 등).

## 시즌이 늘어날 때
1. 기록 시트: `python3 tools/xlsx-to-stats-csv.py <xlsx> <시트> data/stats/<시즌>.csv` (2023-24 200명, 2024-25 203명, 2025-26 193명). 시트는 플레이오프까지 합친 누적이다.
2. 해당 시즌 소속: 선수기록 화면(PTS 순, 1차 스탯)을 페이지를 넘기며 **녹화**한다. 그러면 도구가 팀 아이콘을 읽는다.
   ```bash
   ffmpeg -i 녹화.mp4 -vf fps=2 frames/f%03d.png
   node tools/team-totals.mjs 2023-24 > totals.json
   python3 tools/read-team-icons.py --stats data/stats/2023-24.csv --frames 'frames/f*.png' --first-page 1 --totals totals.json --out data/players/team-2023-24.csv --season 2023-24
   ```
   - 녹화가 중간 페이지부터면 `--first-page`로 알려 주고, 이미 있는 파일에 덧붙이려면 `--append`. 스크린샷 여러 장도 `--frames`에 넘기면 된다.
   - 도구는 프레임을 화면이 바뀌는 곳에서 페이지로 나누고, 통계 시트의 선수 수로 계산한 페이지 수와 맞는지 확인한다.
   - 검증: 선수가 뛴 경기의 팀 승·패가 구단 시즌 합계(정규리그+플레이오프)를 넘으면 표시한다. 시즌 중 이적한 선수가 걸리고(나무위키 트레이드와 일치, 아이콘은 마지막 소속), 판독 오류도 여기서 걸린다. 아이콘 판별 여유가 작은 선수도 알려 준다.
   - 사람이 확인해 정정한 값은 `team-overrides.csv`에 적으면 다음 실행에도 유지된다.
3. 이 도구로 2024-25(1~100위는 스크린샷, 101~203위는 녹화)와 2023-24(전체 녹화)를 읽었고, 25-26 결과(193명)를 같은 도구로 다시 읽어도 달라지지 않았다(24-25 앞쪽 100명으로 확인).
- 2023-24: 200명 중 승·패 한도를 넘은 선수는 듀반 맥스웰 1명(정관장 → 가스공사 이적, 위키와 일치). 2024-25: 시즌 중 이적한 캐디 라렌·디온테 버튼·정효근·최성원, 판별 여유가 작아 위키로 확인한 조상열(가스공사).
