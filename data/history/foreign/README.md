# 역대 외국인 선수 (`foreign/<시즌>.json`)

나무위키 "외국인 선수/역대 프로농구" 문서(2026-10-10 수정본, 사용자 제공)를 시즌별로 옮긴 것. 시즌 이벤트(`../events/<시즌>.json`의 `foreign`)가 계약 종류·연봉 같은 세부를 담는다면, 이쪽은 그 시즌에 뛴 외국인 선수 **명단 전체**(1997~2026-27)다. 문서 설명대로 "경기 출전 기록이 없이 교체된 선수는 누락되어 있을 수도" 있다.

## 형식
```jsonc
{
  "season": "2004-05",
  "system": "자유계약",          // 그 시즌 선발 방식: 드래프트 / 자유계약 / 드래프트(장·단신) 등. 문서 소제목·설명에 있는 말로
  "note": "문서가 그 시즌 앞에 적은 규정 설명 요지(선택)",
  "teams": [                     // 문서의 구단 순서(그 시즌 최종 순위) 그대로
    { "franchiseId": "wonju-db", "team": "원주 TG삼보",       // team = 문서 표기 그대로
      "players": [               // 표의 위→아래, 드래프트 시절은 1라운드 칸 선수들 다음 2라운드 칸 선수들
        { "name": "처드니 그레이", "position": "SG", "heightCm": 186.5, "school": "세인트존스",
          "round": 1,            // 드래프트 시절만 1|2. 아니면 생략
          "type": "장신",        // 2015-16~2017-18만 "장신"|"단신"|"제외"(라건아). 아니면 생략
          "nationality": ["미국", "나이지리아"],   // 문서에 국기 칸이 있는 시즌(2015-16~)만. 국기 이름(예: "미국 국기" → "미국")으로. 없으면 생략 — 추정하지 않는다
          "asiaQuota": false,    // 2020-21~ 아시아 쿼터 표의 선수는 true. 아니면 생략
          "marks": ["mvp", "nba"],   // 아래 표시 표
          "nth": 2,              // "n번째 시즌"이 적혀 있으면
          "status": "신규 영입, 시즌 중 방출",   // 비고 열(또는 괄호) 원문. 2015-16~는 "↖대체 영입"의 ↖를 떼고 "대체 영입"으로
          "note": "각주·괄호 설명 원문(각주 번호는 떼고 내용만)",
          "inherited": ["nationality"],   // 병합 칸이라 위 줄에서 이어받은 키(문서에 그 선수 칸이 없던 경우만)
          "source": "official",   // 문서 표에는 없어서 다른 자료로 보충한 선수만: "official"(KBL 공식 기록에 외국인으로 출전) | "events"(시즌 이벤트 파일). 문서 표의 선수는 생략
          "officialName": "디제이 화이트"   // 공식 기록(data/stats/official)의 표기가 문서와 다를 때만(띄어쓰기·점 차이는 자동으로 무시)
        } ] } ]
}
```
- 값이 문서에 없으면 키를 **생략**한다(null도 되지만 쓰지 않는다). 기억으로 채우지 않는다.
- `position`은 문서 표기 그대로(`C/PF`, `PF,C`, `SF/PF` …). 키는 cm 숫자(각주로 다른 측정치가 있으면 note에).
- 한 선수가 시즌 중 두 구단에 나오면(트레이드) 구단마다 한 번씩 적는다(문서도 그렇다).
- 각주(`[n]`, `[A]`…)는 문서 맨 아래 각주 목록에서 내용을 찾아 해당 선수의 `note`에 옮긴다. 선수 이름에 붙은 괄호 설명(예: "(시즌 전 트레이드)")은 `status`나 `note`에.
- 드래프트 시절 "이름 칸 옆에 (시즌 개막전 교체)처럼 붙은 말"은 그 바로 앞 선수에게 붙은 설명이다. 같은 칸에 이름이 줄줄이 나오면 교체로 들어온 선수들이다(순서대로).
- 한 시즌에 같은 구단의 같은 이름이 두 번 나오는 것은 동명이인일 때만(2010-11 부산 KT 앤서니 존슨 둘).

### 표시(`marks`)
| 문서 | 값 | 뜻 |
|---|---|---|
| ★ | `mvp` | 그 시즌 외국인 선수 MVP |
| ① | `draft1` | 드래프트 전체 1순위 |
| ☆ | `renewed` | 전 시즌 재계약해 연속으로 뜀 |
| ◆ | `contracted` | 2년 이상 계약 중 |
| ⓝ | `nba` | NBA 정규시즌 출전 경험 |
| ※ | `temp` | 부상 선수의 일시 대체 |
| ⊙ | `fullReplaceInjury` | 8주 이상 부상으로 인한 완전 교체 |
| ● | `traded` | 시즌 전·중 트레이드 |
| 그 밖(◎ 등) | `unknown` | 뜻이 문서에 없는 기호는 `unknown`으로 적고 note에 기호를 남긴다 |

### 시대별 표 읽는 법
- **1997~2003-04, 2007-08~2014-15 (드래프트)**: 칸이 구단 / 1라운드(이름·Pos·키·출신교) / 2라운드(이름·Pos·키·출신교). `round`를 채운다. 문서의 "시즌 개막전 교체", "계약 해지" 등은 `status`.
- **2004-05~2006-07, 2011-12 (자유계약)**: 구단 / 외국인 선수(이름·Pos·키·출신교). `round` 없음.
- **2015-16~2017-18 (장·단신)**: 구단 / 성명 / 장단신 구분 / 포지션 / 국적 / 비고. 장단신 칸이 한 번만 나오면 아래 줄도 같은 값이 아니라 **표에 보이는 대로**(병합 칸) 위에서 아래로 풀어 채운다: 표에 `*`는 1라운드(장신)·`#`은 2라운드(단신) 선발 표시. 이름 끝의 `*`·`#`은 떼고 `note`에 쓰지 않아도 된다(`type`에 이미 있다).
- **2018-19~ (자유계약)**: 구단 / 성명 / (장단신) / 포지션 / 국적 / 비고. 포지션·국적·장단신이 병합 칸으로 한 번만 나오는 경우가 많다: 같은 구단의 아래 줄에 그 칸이 없으면 **바로 위 줄 값을 이어받되**, 이어받은 키 이름을 `"inherited": ["position", "nationality"]`처럼 적는다(문서에 그 선수 칸이 없었다는 표시. 병합 칸이라 같은 값이 거의 맞지만 아닐 수도 있어, 나중에 다른 시즌·이벤트의 같은 선수 값과 대조한다).
- **아시아 쿼터**(2020-21~): 따로 표가 있다. 같은 시즌 파일의 해당 구단 `players`에 `"asiaQuota": true`로 넣는다. 그 구단의 외국인 표에는 없고 아시아 쿼터 표에만 있는 구단도 있다.

### 국적 표기
국기 이름으로 적는다("미국 국기" → `미국`, "푸에르토리코 기" → `푸에르토리코`). 코드(USA 등)가 국기 이름과 어긋나면(문서 오타: LVN/LBN, CAN인데 미국 국기 등) **국기 이름**을 쓰고 `note`에 어긋남을 적는다.

## 검증 (`node tools/check-foreign.mjs <시즌>`)
- **오류**: 형식, 구단이 그 시즌 구단과 다르거나 빠짐(`node tools/check-foreign.mjs --teams <시즌>`로 franchiseId 목록을 본다), **공식 기록에 그 구단 외국인으로 출전한 선수가 문서 표에 없음**(철자가 다르면 `officialName`).
- **경고**: 표에는 있는데 공식 기록에 출전 기록이 없는 선수(시즌 전 교체·계약 해지 등은 정상. 그런 경우 `status`/`note`에 이유가 있어야 한다), 이벤트 파일의 외국인이 표에 없음.
