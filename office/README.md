# 에이전트 오피스 (픽셀 오피스) 소스

- 게시 주소: https://claude.ai/artifact/HbVEtrL8vYJGQ3gzvByX5r (db 컬렉션 `agents` / `feed` / `office`는 읽기만 한다)
- `office3.html` — 페이지 본체(캔버스 + 인라인 JS/CSS). 이미지 에셋(`assets/…`)을 불러오고, 실패하면 코드로 그린 캐릭터·소품으로 대신한다.
- `assets/atlas.png` `props.png` `atlas.json` — 사용자가 만든 캐릭터·소품 시트(`source/sheet.webp`, 초록 배경)에서 잘라 낸 컷아웃. 캐릭터 컷(`atlas.png`)은 원본(약 60~90px)을 2배(`atlas.json`의 `up`)로 키우고 선명하게 다듬은 것이다. 게임이 화면 픽셀 해상도의 캔버스에 줄여 그리므로 흐려지지 않는다(원본을 1.3~1.6배 늘려 그리던 때가 흐려 보이던 원인).
- `make-atlas.py`, `cutout.py` — 시트 → 에셋 변환(크로마키 제거, 초록 번짐 제거, 연결 성분 분리, 패킹). `python3 office/make-atlas.py`
  - 컷 번호(`CHARS`, `BOSS`, `PROP_COMPS`)는 시트를 눈으로 보고 정한 목록이다. 시트를 바꾸면 `/tmp`에 번호 표시 이미지를 만들어 다시 확인한다.
- `source/sheet.webp`, `source/building-ref.webp` — 사용자가 올린 시트와 완성 건물 참고 이미지(시안). `source/sheet2.webp`, `source/building-ref2.webp` — 전설 포켓몬·굼바·부끄왕이 든 두 번째 시트와 6층 시안. `source/sheet3.webp`(76.webp) — 루나아라·아르세우스·제크로무·카멕이 든 세 번째 시트(`source/sheet4.webp`는 78.webp 사본, 지금은 쓰지 않는다). `make-atlas.py`가 세 시트를 한 아틀라스로 합친다(`atlas.json`의 `extra`).

## 움직임(이동) 규칙 요약
- 걷기는 가속→순항→감속(순간이동 없음), 걸음마다 통통·기울임, 방향 전환은 몸을 좁혔다 펴며 뒤집기, 도착하면 살짝 튕김, 앉기·일어나기는 부드럽게 가라앉았다 올라오기.
- 엘리베이터: 문 앞 대기 → 문 열림 → 걸어 들어가 카 안에 섬 → 문(유리) 닫힘 → 가속·감속 이동 → 열림 → 걸어 나옴. 유리문이라 타고 있는 캐릭터가 계속 보인다.
- 층 바꿔야 하는 출근·보고·반려도 모두 걸어서 이동한다(새 직원만 입구에서 페이드로 나타난다). 편지·뮤 비서는 곡선 경로로 천천히 출발·도착한다.

## 로컬 확인
`office/office3.html` 앞뒤에 `<!doctype html>…<body>` 틀을 붙이고 `assets/` 와 함께 정적 서버로 서빙해 연다(`window.claude`가 없으면 예시 직원 10명으로 렌더된다).

## 하루 주기와 건물 구성(6층)
- **낮·밤은 현지 시각이 아니라 가속 주기**로 돈다(`CYC`): 페이지를 연 시각부터 (경과 초 mod 77). 낮 52초 + 밤 25초, 전환 때 2.5초에 걸쳐 장면 전체가 어두워진다(`nightK`). 상단 "시간대" 버튼은 **낮·밤 자동 순환 → 밤 고정 → 낮 고정**을 돌아가며 고른다(고정이면 일과 장면은 걸리지 않는다).
- 주기 위상으로 거는 일과(`SCHED`, 낮 구간 초): **12초 사장님 순시**, **34초 간식 사건**(시작 간격 22초). 낮→밤이 되면 전설 **근무조 교대** 장면이 걸린다. 지나간 이벤트는 다시 하지 않고 지금 시작하는 것만 재생한다. 일과 장면은 `AMB_K=2.8`배속(데모는 2.2배속)으로 돌고, 주문·보고 같은 실제 장면이 오면 그것이 앞에 서고 재생 중인 일과는 빨리 감아 끝낸다.
- 6F 사장실 / 5F 기획·규칙실 / 4F 개발실 / 3F 휴게·회의실 / 2F 화면·디자인실 / 1F 데이터·검수·배포.
- **자리**: 모두 기본은 자기 층 자리에 상주한다. 책상 6개 → 서 있는 자리 5개(`FSTAND`) → 넘치면 3F 휴게실(앞줄 6 + 로프트 10 = 16자리, 넘치면 "+N명"). 일하는(working) 직원은 책상에서 모니터를 보고, done·idle 직원은 자기 자리에서 한가하게 앉아 있다(졸기·두리번·간식·모니터 구경 중 id 해시로 하나). 일하는데 책상이 없으면 쉬는 직원의 책상과 바꾼다. 보고(done)를 마치면 사장실에서 내려와 자기 층 자리로 돌아간다.
- **휴게실 방문**(`VISIT`, 실시간 초): 쉬는 직원은 40~110초 뒤 처음, 이후 90~150초마다 3F에 가서 20~40초(이동 8초 포함 별도) 쉬고 돌아온다. 출발 시각은 에이전트 id 해시로 분산(결정적), **동시에 최대 3명**.
- **퇴근·야근**: 밤이면 일하지 않는(done·idle) 직원은 엘리베이터로 1층 출입구까지 내려가 걸어 나가 사라지고, 낮이 오면 출입구로 들어와 자기 자리로 간다. 일하는 직원은 야근으로 자리에 남는다. 출퇴근·방문 무리는 같은 층에서 같은 곳으로 가면 **한 카에 최대 4명**이 함께 타고(카·문 2.2배, 걸음 1.8배), 보고·주문 같은 일반 이동은 혼자 탄다. 모두 연속 보간(순간이동 없음).
- **보고 자리**: 보고·반려 때는 사장님 책상 왼쪽 모서리 `REPORT_X=234`(사장님 `BOSS_X=270` 바로 앞 36px)에 선다. 전설 직원 자리(x 22~184)와 겹치지 않는다.
- **전설 직원 7마리**(사장실 왼쪽 자리 7칸, 에이전트 아님, db에 없음): 솔가레오(낮 근무)·펄기아·디아루가·아르세우스·제크로무·네크로즈마(상시)·루나아라(밤 근무). 밤이 되면 솔가레오가 퇴근하고 루나아라가 출근한다(엘리베이터로 1층 출입구 ↔ 사장실). **모두 사용자 시트에서 오린 컷**이다(아래 표). 시트에 **기라티나 컷은 없어서** 코드로 그려 넣지 않고 그 자리를 시트의 다른 전설 컷(제크로무)이 맡는다(건물 직원 패널에 "기라티나: 컷 없음"으로 표시). 일하는 에이전트가 없으면 사장님이 심심해하고, 주문이 내려오면 전설들이 "!" 하며 뛴다.
- **간식 사건**(낮 34초): 전설 둘이 몰래 엘리베이터로 3F에 내려가 간식을 훔쳐 먹고(자판기 위 "간식 ■■■"가 줄어든다), 휴게실 단골 **이브이·피카츄**가 보고 굼바를 부른다. 3F 굼바가 달려와 혼내고, 울다가(눈물) 간식을 다시 채운다. 전설들은 사장실로 돌아간다. 이브이·피카츄는 에이전트에게 주지 않는 종으로 예약(`SPRES`)되어 중복이 없다.
- **사장님 순시**(낮 12초): 사장님이 책상(빈 책상이 남는다)에서 일어나 엘리베이터로 4F → 3F를 돌며, 그 층에서 일하지 않고 있는 직원(휴게실 단골 포함)이 있으면 **그 자리에서 함께** 혼낸다("죄송합니다…"). 끝나면 책상으로 돌아온다.
- **굼바 6마리**: 층마다 한 마리씩 자기 층 바닥만 닦는다(층별 모자 색). 엘리베이터는 타지 않는다(간식 사건 때 3F 굼바만 불려 간다). 누르면 한마디 한다.
- **마귀 2마리**(카멕 컷, B는 같은 컷의 색조만 바꾼 것): 쉬지 않고 층을 돌며 순찰하다가 **일이 막힌 직원**(item이 fix, 상태에 막힘·모름·오류·수정 같은 말, 반려 직후 90초)을 발견하면 달려가 마법으로 돕는다("이렇게 해 보세요!"). 막힌 직원 머리 위에는 "?"가 뜬다. 같은 직원은 120초 안에 다시 돕지 않는다.
- **킹부끄**: 밤(주기 25초 구간 또는 "밤 고정")에 나타나 벽을 통과해 돌아다닌다. **분신 3마리**(같은 컷, 색조·투명도만 다름)가 빈 층(없으면 혼자 일하는 층)을 골라 밤새 계속 옮겨 다닌다(걸리거나 이르지 않고, 사람 수·겹침 계산에 들어가지 않으며 서로 34px 이상 떨어져 선다). 본체는 굼바나 혼자 일하는 직원에게 걸리면 사장님께 일러바친다. **노출 규칙**: 그 층에서 일하는 직원이 1명이면 늘 선명히 보이고, 2명 이상이면 보이지 않으며(그 층은 피한다), 아무도 없으면 반투명이다. 누르면 걸린다(본체만).
- **데모 버튼**: "데모 재생"은 주문→출근→보고→반려→재보고→킹부끄(옛 흐름), "일과 데모"는 간식 사건→순시→마귀의 지원→전설 야간 교대→킹부끄(약 1분). 둘 다 화면만 바꾸고 db는 건드리지 않는다.
- 에이전트가 아닌 직원(전설·굼바·마귀·단골·사장님 순시 모습·킹부끄)은 db를 읽지 않고, 겹침·종 중복 검사 대상도 아니다. 이미지를 못 불러오면 굼바·킹부끄는 단순한 코드 모양, 전설·마귀·단골은 색 원 + 이름 첫 글자 아이콘으로 대신한다(캐릭터를 코드로 그려 넣지 않는다). 움직임 줄이기 설정이면 일과가 3배속으로 돈다.
- 접근성: 일과 장면마다 `aria-live` 문장이 나가고("사장님이 순시를 나섭니다", "굼바가 간식을 다시 채웠습니다" 등), 건물 직원 패널에 시계·직원 상태가 글로 나온다.
