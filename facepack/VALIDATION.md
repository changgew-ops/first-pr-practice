# 검증 기록

- 1,454개 선수 ID의 중복 없음과 매핑 확인.
- photo=true 1,275개 WebP 전부 디코딩 검증.
- fallback 179개 모두 gen-01 ~ gen-16 범위의 고정 얼굴 매핑 확인.
- 실제 사진별 로컬 자산 조각 파일 참조 검증.
- 브라우저에서 전체 목록 검색/페이지 표시, 과거 선수 허재 사진 표시 확인.
- HTTP 최소 연동 예제에서 real / fallback / generated 세 경로와 유니폼 합성 확인.
- HTTP에서 offline=true 경로를 사용해 로컬용 boot.js / photos-XXX.js 자산 로딩 확인.
- 실제 file:// URL은 검수용 클라우드 브라우저 정책상 차단되어 직접 실행 검증하지 못함. 사용자 PC의 로컬 실행은 연동 후 확인 필요.
- JavaScript 구문 검사와 ZIP CRC 검증 통과.

전체 인물의 신원과 합성 결과를 수동 전수 검수한 것은 아님. 자동 얼굴 검출 실패 25명은 점검 표시로 보존함.
최종 게임 코드는 제공받지 못했으므로 게임 안의 세이브/이적/우승 화면 연결은 Claude Code 연동 후 검증해야 함.
